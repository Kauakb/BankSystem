# Security Policy

## Supported versions

Only the latest code on `main` (and the latest GitHub release) receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/Kauakb/BankSystem/security/advisories/new)
(repo **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it, and what impact you think it has.
This is a student project maintained by one person, so replies may take a few days.

## Data

`Applicants_Form.txt` contains fictional example data. Never commit real personal data to this repository.
